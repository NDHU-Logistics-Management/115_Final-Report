## 資料能確認的事

1. **部分距離表把去程與回程寫在同一個方向裡**，起訖站與中途站各出現兩次，兩次累積里程差一整圈：臺東公路 8101A／B／C／D、8168A 方向 0，花蓮市區 309 方向 0。
   8101A 方向 0：台東轉運站以兩個代碼列出（300031 站序 1 = 0 km、300030 站序 11 = 236.78 km），台東火車站同代碼列兩次（站序 2 = 7.61、站序 10 = 230.45）。
2. **票證分成兩群，各自帶其中一種代碼。** 8101A 方向 0「台東轉運站→小野柳」10,478 筆：帶 300031 者 5,297 筆算出 +117.13 km，帶 300030 者 5,181 筆算出 −119.65 km。整併版 `abs()` 取正計入 119.65，獨立腳本「只留 > 0」整筆丟棄。不是配對規則選錯：72.7% 的票證兩端候選數皆為 1，規則不會啟動。
3. 配對上下車各自獨立，不檢查下車站序在上車之後，會產生依表順序不成立的組合。8101A 方向 0 站序 2→3 為 109.51 km，是次大段（42.65）的 2.6 倍；里程區間涵蓋該段的票證 18,604 筆（27.6%），平均 abs 里程 164.79 km，未涵蓋者 36.18。
4. 8101A 方向 0 全長 236.8 km、11 列；8101D 方向 0 全長 100.8 km、8 站，其中兩段 31.0、20.9 km。這些段值是否正確未核對。
5. 上下車同站（差 = 0）：整併版計入、獨立腳本排除。臺東市區 13,465 筆（4.2%），月平均差 −0.19 km。定義問題，兩邊都未說明。

## 負值的來源，以及 `abs()` 為何都不對

距離表**首站與末站為同一實體站牌**（閉合表）時，該方向含去程與回程。四份距離表共 16 個閉合表：臺東公路 8101A–D、8168A 方向 0（6）；花蓮市區 302A／307／311 兩方向、309 方向 0（6）；臺東市區 101、市區循環 兩方向（4）。

| 情形 | 判別 | 該用的算式 |
| --- | --- | --- |
| 順向未過終點 | 差 > 0 | 下車 − 上車 |
| 順向但坐過終點 | 閉合表且差 < 0 | 環繞 = 全長 − 上車 + 下車 |
| 定位到同一站牌的另一次出現（實際未繞圈） | 閉合表且差 < 0 | 同站牌另一次出現的短距離 |
| 方向欄位錯置或表非閉合 | 非閉合表且差 < 0 | 個案判斷 |

負值票證落在閉合表的比例：臺東公路 98.2%、花蓮市區 85.7%、臺東市區 0%（2,962 筆全在非閉合的陸海空線C）。

對 8101A 方向 0 第二群套環繞公式：236.78 − 236.78 + 117.13 = **117.13**，與第一群相同；`abs()` 給 119.65。不論這 5,181 筆是真的坐過終點還是只是定位到另一次出現，答案都是 117.13。兩群的刷卡時距分布完全相同（中位數與平均皆 1 小時），支持它們是同一種搭乘。

**但環繞公式修不了段值本身。** 8101A 方向 0 表列 117.13 km 的區間與表列 13.29 km 的區間時距分布相同（中位數皆 1 小時）；表列 35.87 km 的區間 88.6% 時距為 0 小時，13.29 km 者 0%。309 方向 0 表列 49.37 km 的區間 27.3% 時距 ≥2 小時，`abs()` 給 77.42 km 那組只有 1.1%（環繞給 32.40）。順序關係與表列距離不一致，需外部核對。
