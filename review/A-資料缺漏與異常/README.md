## output/ 注意

`A5b-花蓮市區全路線五次以上卡數_逐月.csv` 為一次性產出，**沒有腳本**。它排除了全部站牌 -99 的列，比 A7 去重更寬，因此 113/06–114/12 各月「全體五次以上」比表 3.1.2 少 1–32 張（平均 12）。逐路線組成與比例可用，絕對張數不可與表 3.1.2 對齊。
