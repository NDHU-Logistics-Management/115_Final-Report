## 常設規則

| 規則 | 理由 |
| --- | --- |
| docx 一律手動編修，不用程式改 | 二進位檔無法 diff，改動逐列記在 `revise/docx套入清單.md` |
| 要改計算或圖表，直接改 `revise/code/115期末-修訂.Rmd`，改完跑 `run-all.R` | 原稿 Rmd 已停用；與原稿的差異用 `git diff --no-index` 兩檔即可看 |
| 資料異常只寫已確認的事實，不寫推測性成因 | 例：花蓮市區 TO2A 逐日更新、A1 勒索病毒皆有平臺依據；未確認者寫「尚待確認」 |
| 比較兩種算法只寫資料能證明的差異，不判哪邊正確 | 正確與否需外部依據（TDX 座標、業者里程表）；沒有就標「待核對」（C5） |
| repo 內部分析（如 A6 回填評估）不寫入報告 | |
