## 工作順序

數字先於文字，文字先於 docx。

1. **code/**　複製 Rmd → `python patch-rmd.py` → `Rscript run-all.R`。要改程式就改 patch-rmd.py 再重跑，不直接改 Rmd
2. **output/**　跑 `對帳.R`，確認哪些文字引用的數字變了
3. **text/**　帶入新數值改定稿；每段格式 `### §章節　標題　[項目編號]` → **動作** → **定稿**，項目編號對應 `../review/問題清單.md`
4. **docx**　逐章換圖、貼文字、加註；每完成一章在 `修訂對照表.md` 打勾並 commit

## 注意

- docx 為二進位檔，git 無法 diff。改動說明一律寫在 `修訂對照表.md`，commit 訊息註明完成的章節。
- 內文一律以「業者未提交資料至平臺／資料不完整」表述，勒索病毒等細節只寫在第 6 章。
- 甲案：維持 113/06–115/06 全區間，表格保留數值並加註，趨勢線標記斷點，文字不涵蓋受影響月份。
- 平均每日使用次數折線圖的 Y 軸標題用「平均每日使用次數」（不用「均日使用次數」），與表格欄位同名。
- 花蓮市區客運資料等級為 TO2A（卡號逐日更新），區間人數的意義與其他三組不同：章節開頭要說明，表格欄位名用「月搭乘次數」與「日搭乘次數」區別。
- 其他所有裁示見 `../review/裁示紀錄.md`。
