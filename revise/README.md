## 工作順序

數字先於文字，文字先於 docx。

1. **code/**　改對應章節的 `.R`（清理規則改 `03_clean_data.R`、路線清單改 `02_route_list.R`），然後 `Rscript revise/code/run-all.R`。它會重出全部圖表並對帳（新 xlsx vs 原稿 xlsx 逐格、與 review 稽核重算交叉）。只改一章時可在 RStudio 直接 source 該章檔
2. **output/**　看 run-all 印出的對帳結果；在 `重出紀錄.md` 加一列，寫差異落在哪
3. **text/**　帶入新數值改定稿。每段格式：`### §章節　標題　[項目編號]` → 原稿起首 → 動作 → 定稿；檔末有本章數字核對表。項目編號對應 `../review/問題清單.md`
4. **docx**　照 `docx套入清單.md` 逐列做；一章做完 commit，訊息寫章節
