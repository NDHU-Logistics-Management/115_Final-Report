問題、證據與決定在 [`../review/`](../review/)；本資料夾只放修訂成果。

## 讀法

- 想知道做到哪：下方「狀態」表。
- 要套 docx：開 [`docx套入清單.md`](docx套入清單.md) 逐列做、打勾。
- 想知道數字為什麼變：[`output/重出紀錄.md`](output/重出紀錄.md)。
- 想知道為什麼這樣改：`../review/裁示紀錄.md`。

## 工作順序

數字先於文字，文字先於 docx。

1. **code/**　複製 Rmd → `python patch-rmd.py` → `Rscript run-all.R`。要改程式就改 patch-rmd.py 再重跑，不直接改 Rmd
2. **output/**　跑 `對帳.R`；在 `重出紀錄.md` 加一列，寫差異落在哪
3. **text/**　帶入新數值改定稿。每段格式：`### §章節　標題　[項目編號]` → 原稿起首 → 動作 → 定稿；檔末有本章數字核對表。項目編號對應 `../review/問題清單.md`
4. **docx**　照 `docx套入清單.md` 逐列做；一章做完 commit，訊息寫章節

## 注意

- docx 為二進位檔，git 無法 diff。docx 一律手動編修，改了什麼以 `docx套入清單.md` 的打勾與 commit 訊息為準。
- 內文一律以「業者未提交資料至平臺／資料不完整」表述，勒索病毒等細節只寫在第 6 章。
- 甲案：維持 113/06–115/06 全區間，表格保留數值並加註，趨勢線標記斷點，文字不涵蓋受影響月份。
- 平均每日使用次數折線圖的 Y 軸標題用「平均每日使用次數」（不用「均日使用次數」），與表格欄位同名。
- 花蓮市區客運資料等級為 TO2A（卡號逐日更新），區間人數的意義與其他三組不同：章節開頭要說明，表格欄位名用「月搭乘次數」與「日搭乘次數」區別。
- 執行 run-all.R 前關閉 Excel 中的 output xlsx，否則寫檔失敗會留舊表（腳本會檢查鎖定檔並中止）。
