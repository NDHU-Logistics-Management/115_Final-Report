## 二、解釋以下問題
1.	報告書第256頁有關花蓮縣TPASS推動成效：【平均每日使用次數及其族群分布】
搭乘次數「僅一次」類型於114年12月佔31.2%，此部分是否為平均每天使用一次? 該類民眾一天只用一次TPASS的原因為何? 誘因似不強烈，請中心進一步了解及分析後補充說明。

114年12月搭乘次數「五次以上」類型佔40.8%，建議中心進一步分析其旅運行為模式或族群特性，以利掌握主要客群之使用需求。

報告書第256頁有關TPASS成效分析，由於推出政策的目的係希望民眾能改變旅運行爲，而使用次數則是重要的指標，建議中心進一步分析每月使用5次以上類型之高度使用公共運輸族群者之旅運行為及特性。
